Case 1

🏚️ The House

A real house in Belgium kept a log of every room, every 10 minutes, for four months. The spirit meter (TabPFN) learned what each night should feel like. Luna, Dr. Bigotes and Xochi read the nights that broke the pattern.

    🧰What is in the kit

    • The spirit meterTabPFN, an open tabular foundation model, reads the house's last 14 days in context and predicts a range for every room, every 10 minutes. Readings far outside it are apparitions.
    • The crewLuna, Dr. Bigotes and Xochi are Gemma 4 running on your own machine through Ollama, each with a personality and a job.
    • Cite or vanishGenerated story sentences need a known citation and numbers within the validator's tolerance. This checks references and numbers, not explanations or supernatural claims. Quiet nights use labeled scripted summaries.
    • The watch never sleepsEach night is a durable Temporal workflow. Kill the worker or the model mid-night and it picks up where it stopped.
    • VoicesRecorded application voices use ElevenLabs. Audio is shown only when its saved text matches the displayed story.
    • Private by designA house's night logs say when people sleep and when the house is empty. A home install can run locally. This demo replays the house investigations; opening a live board sends evidence summaries, questions and optional memory text to the server and, when configured, its model provider.
